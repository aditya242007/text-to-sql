# Workflow: next-phase
1. Read docs/PROGRESS.md to find the last completed phase.
2. Read the next phase section in docs/PHASE_PROMPTS.md and the matching PRD sections.
3. Produce an Implementation Plan and wait for approval.
4. Implement only that phase, run ruff and pytest, and show real output.
5. Update docs/PROGRESS.md and docs/DECISIONS.md.
6. Summarize and stop. Do not start the following phase.
